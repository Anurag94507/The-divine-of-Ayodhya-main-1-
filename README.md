Featuring comprehensive temple guides, darshan timings, authentic Satvik bhojnalaya directories, dharmshala & hotel bookings, live donations via Razorpay, and direct contact support.

## 🛠️ Technology Stack

### Frontend:
- **Framework:** React 18 with TypeScript
- **Build Tool:** Vite 5 with SWC
- **Styling:** Tailwind CSS 3 with `@tailwindcss/typography` & `tailwindcss-animate`
- **UI Components:** Radix UI primitives & Shadcn UI
- **Icons:** Lucide React
- **Notifications:** Sonner & Radix UI Toast
- **Payment Gateway:** Razorpay Standard Checkout SDK

### Backend:
- **Runtime:** Node.js (v18+)
- **Server Framework:** Express.js (v4.21+)
- **Email Service:** Nodemailer (Gmail SMTP integration)
- **Payment Processing:** Razorpay Node SDK
- **Security & Utilities:** CORS, Dotenv, Crypto

## 🚀 Quick Start & Local Development

### 1. Prerequisites
- **Node.js** (v18.0.0 or higher) - [Download Node.js](https://nodejs.org/)
- **npm** or **bun** / **yarn** / **pnpm**

### 2. Clone the Repository
```bash
git clone https://github.com/KeyToCoding/ayodhya-blossom-experience.git
cd ayodhya-blossom-experience
```

### 3. Install Dependencies

**Option A: Using root script**
```bash
npm run install:all
```

**Option B: Manual install**
```bash
# Install frontend packages
cd frontend
npm install

# Install server packages
cd ../server
npm install
```

### 4. Configure Environment Variables

Create `.env` in `server/` directory:
```env
PORT=5000
EMAIL_USER=your-email@gmail.com
EMAIL_PASS=your-google-app-password
RAZORPAY_KEY_ID=rzp_test_sS4pKgwR9F3SU7
RAZORPAY_KEY_SECRET=your_razorpay_secret_key
```

*(Optional)* Create `.env` in `frontend/` directory for custom backend URL:
```env
VITE_API_URL=http://localhost:5000
```

### 5. Run the Application

In terminal 1 (Frontend):
```bash
cd frontend
npm run dev
```
> 🌐 Frontend will start at: `http://localhost:3001` or `http://localhost:5173`

In terminal 2 (Backend Server):
```bash
cd server
npm start
```
> 🚩 Server will start at: `http://localhost:5000`

## ⚙️ Environment Variables

| Variable | Scope | Description | Default / Example |
| :--- | :--- | :--- | :--- |
| `PORT` | Server | Port for the Express backend | `5000` |
| `EMAIL_USER` | Server | Gmail address for receiving contact inquiries | `devotee@gmail.com` |
| `EMAIL_PASS` | Server | Google 16-character App Password | `abcd efgh ijkl mnop` |
| `RAZORPAY_KEY_ID` | Server | Razorpay Key ID (Test or Live) | `rzp_test_...` or `rzp_live_...` |
| `RAZORPAY_KEY_SECRET` | Server | Razorpay Secret Key | `secret_...` |
| `VITE_API_URL` | Frontend | Backend API endpoint URL for production | `https://your-backend.onrender.com` |

## 🌐 Deployment Guide

### 1. Deploy to Vercel (Recommended)

#### Method 1: Deploy via Vercel Dashboard (Zero Setup)
1. Push your code to **GitHub**.
2. Log in to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import your **`The-divine-of-Ayodhya`** repository.
4. Set the following in project settings:
   - **Framework Preset:** `Vite`
   - **Root Directory:** `./frontend` *(or leave as root `./` as `vercel.json` is already configured)*
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
5. In **Environment Variables**, add:
   - `VITE_API_URL`: Your deployed backend URL (e.g. `https://your-server.onrender.com` or leave empty for frontend-only).
6. Click **Deploy**! 🚀

---

### 2. Deploy to Replit

1. Fork or import this repository into [Replit](https://replit.com).
2. The project contains pre-configured `.replit` and `replit.nix` files.
3. Click the green **Run ▶** button at the top.
4. Replit will automatically install dependencies and launch the live web preview!

---

### 3. Deploy Backend to Render / Railway

To run the Node.js Express server with live email and Razorpay webhooks:

1. Create a new **Web Service** on [Render](https://render.com) or [Railway](https://railway.app).
2. Connect your GitHub repository.
3. Set **Root Directory** to `server`.
4. Set **Build Command** to `npm install`.
5. Set **Start Command** to `node server.js`.
6. Add your environment variables (`EMAIL_USER`, `EMAIL_PASS`, `RAZORPAY_KEY_ID`, `RAZORPAY_KEY_SECRET`).
7. Copy your Render backend URL (e.g., `https://ayodhya-api.onrender.com`) and add it as `VITE_API_URL` in your Vercel frontend!

## 📡 API Documentation

| Method | Endpoint | Description | Sample Payload |
| :--- | :--- | :--- | :--- |
| `POST` | `/api/send-message` | Submits contact form, saves to JSON & emails admin | `{ "name": "Rohan", "email": "r@example.com", "phone": "9876543210", "subject": "Darshan Info", "message": "..." }` |
| `GET` | `/api/contact-messages` | Retrieves all saved contact inquiries | *None* |
| `GET` | `/api/razorpay-key` | Fetches active public Razorpay Key ID | *None* |
| `POST` | `/api/record-payment` | Confirms payment ID, stores donation & emails receipt | `{ "razorpay_payment_id": "pay_...", "amount": 501, "donor_name": "..." }` |
| `GET` | `/api/donations` | Retrieves list of recorded donations & total sum | *None* |
| `GET` | `/api/health` | Backend status and configuration healthcheck | *None* |
