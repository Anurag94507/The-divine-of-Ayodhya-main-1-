## ✨ Key Features

- 🏨 **Hotels & Dharmshala Directory:** Curated accommodations, amenities, contact details, and booking links.
- 🛕 **Temples & Darshan Guide:** Ram Janmabhoomi Mandir, Hanuman Garhi, Kanak Bhawan, and Raja Dasharath Mahal.
- 🌊 **Saryu Ghat Experience:** Sacred river information, daily Maha Aarti timings, and photo gallery.
- 🍲 **Satvik Bhojnalaya:** Guide to authentic Awadhi pure vegetarian dining and free prasad Annakshetras.
- 💳 **Live Razorpay Donations:** Instant donation processing with downloadable receipt generation.
- 📬 **Interactive Contact Form:** Direct inquiries dispatched to Gmail and recorded locally.
- 📱 **Mobile First & Responsive:** Spiritual saffron & burgundy aesthetic with smooth UI animations.

## 🚀 Quick Start (Frontend)

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build for production
npm run build
```

---

## 🌐 Deployment on Vercel

1. Import this repository in [Vercel](https://vercel.com).
2. Set Root Directory to `frontend`.
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Click **Deploy**.
